# Video transcripts

Put a transcript here to show it on that video's page (dhunlabs.studio/learn/<slug>),
in a collapsible "Transcript" box. It is shown exactly as written, Hindi/Hinglish included.

- File name: the video's YouTube ID, e.g. `3FinJRARyTI.txt` (plain text) or `3FinJRARyTI.srt` (subtitles).
- Plain text: keep paragraphs separated by an empty line.
- .srt files: the numbering is hidden; timestamps are kept as [00:01:02] at the start of each line.
- No transcript file = no transcript box on the page.
